## Volt Launcher 1.0.0

The first full release of Volt Launcher.

### Highlights
- Brand-new Volt UI: lobby home screen, Mods, Shaders, Controls Studio, and the in-game V overlay
- Dozens of built-in pure-Rust mods ported from the Horizon PC registry — no Java, no .jar files
- Volt Shaders with performance tiers tuned for phone GPUs, off by default and free when off
- Volt Replay: native recorder with 360p–1440p capture at 30–144 FPS, plus replay rendering
- Touch controls: full per-button editor with layout import from Pojav-family launchers and Aerix
- Waypoints, Minimap, Volt Boost, FPS overlay, and a built-in recipe viewer
- Ely.by, Microsoft, and Offline accounts with server-wide skins and capes
- Discord Rich Presence, plus Discord and website shortcuts on the title screen
- Safer installs: Volt no longer requests the "install other apps" permission — updates now download through your browser, which removes the biggest Play Protect warning trigger

### Install
Download the APK for your device below (most phones: `arm64-v8a`), open it, and confirm the install.
SHA-256 checksums for every asset are in `SHA256SUMS.txt`.
